THE ARCHITECTURE

/// SYSTEM OVERVIEW

Engineered a comprehensive Relational Database Management System (RDBMS) to digitize inventory and sales workflows for a high-volume bakery.

The core challenge was managing the complexity between raw material consumption and product sales. I designed a 3NF Normalized Schema to eliminate data redundancy and implemented PL/SQL Triggers that automatically deduct ingredient stocks (e.g., flour, sugar) whenever a final product is sold. This automation ensures real-time inventory accuracy.

TECHNOLOGY STACK
Oracle Database 21c / PL/SQL Automation / ERD Design
