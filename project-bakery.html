/// SYSTEM OVERVIEW

Designed a Database Logic System to manage inventory for a bakery business. The goal was to fix the messy manual recording of stock and sales.

I focused on the Entity Relationship Diagram (ERD) to ensure every transaction (bread sold) automatically updates the raw material stock. This project taught me how to translate real-world business problems into structured data tables using Oracle SQL.
